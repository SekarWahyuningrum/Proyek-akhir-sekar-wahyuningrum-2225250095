# Test Case Program Rekap dan Analisis Nilai Matematika

## Tujuan Pengujian
Pengujian dilakukan untuk memastikan program dapat membaca data siswa, menghitung hasil analisis nilai, dan menangani input yang tidak valid dengan benar.

## Daftar Test Case

| ID | Skenario Pengujian | Input/Kondisi | Hasil yang Diharapkan | Status |
|---|---|---|---|---|
| TC01 | Menguji perhitungan rata-rata | Nilai 80, 70, 90 | Rata-rata nilai adalah 80 | Belum diuji |
| TC02 | Menguji nilai minimum | Nilai 0 | Nilai 0 diterima sebagai nilai yang valid | Belum diuji |
| TC03 | Menguji nilai maksimum | Nilai 100 | Nilai 100 diterima sebagai nilai yang valid | Belum diuji |
| TC04 | Menguji nilai di luar batas | Nilai 105 | Nilai ditolak karena melebihi batas maksimum 100 | Belum diuji |
| TC05 | Menguji file yang tidak ditemukan | File data tidak tersedia | Program menampilkan pesan bahwa file tidak ditemukan | Belum diuji |

## Kesimpulan
Test case disusun untuk menguji kondisi normal, kondisi batas, dan kondisi tidak valid. Hasil pengujian akan dicatat setelah program dijalankan. Jika hasil aktual sesuai dengan hasil yang diharapkan, pengujian dinyatakan berhasil.
